# 🕒 Digital Clock

A simple and responsive **Digital Clock** built using HTML, CSS, and JavaScript. It displays the current time dynamically and updates every second.

---

## 🌟 Features
- Displays real-time digital clock  
- Automatically updates every second  
- Clean and responsive design  
- Works on all modern browsers  

---

## 🛠️ Technologies Used
- **HTML** – Structure  
- **CSS** – Styling and layout  
- **JavaScript** – Functionality and dynamic updates
